🚨***Some features may not be still out/developed yet. Users are hoped to wait for updates(I am a human).*** 

### What is FortisDo?
– *FortisDo is a structural, gamified, strategic and analytical productivity app mainly built for students to help them excel in their studies and stay consistent towards their goal.*

### Main Features 
- Timer With Pomodoro Presets (Customisable) including a looping system that loops the timer with breaks for a certain, set interval.
- Stopwatch to track one-go study session.
- Custom Study time logging. For missed tracks.

### Advance Features
- Unbiased Leaderboard ranking with variable time spans.
- A progressive Rank system. Ranks include 12 progression stages, as followed — ***Unknown**(least) > **Neophyte** > **Awakened** > **Forged** > **Relentless** > **Tactical** > **Vanguard** > **Elite** > **Apex** > **Paragon** > **Transcendent** > **Conqueror(highest)***
- Achievements.(will be derived on later)
